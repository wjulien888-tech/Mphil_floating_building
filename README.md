# MPhil Floating Building - 水上建筑能源分析

MPhil研究项目，针对水上浮动建筑进行光伏发电潜力评估、建筑负荷建模及供需匹配分析。

## 研究背景

水上浮动建筑作为一种新型建筑形态，其能源系统设计面临独特挑战：

1. **水面微气候影响**：水面反照率高于陆地，且水体冷却效应可提升光伏组件效率
2. **BIPV集成设计**：球形建筑采用多朝向光伏一体化设计，需精确计算各表面辐照量
3. **负荷特性复杂**：水上建筑的使用模式、空调需求与陆上建筑存在差异
4. **能源自持目标**：需要评估光伏发电是否足以支撑建筑运行

本研究通过建立物理模型，对上述问题进行定量分析。

## 项目概述

**研究对象**：水上浮动建筑（球形主体 + 甲板平台）

**研究内容**：
- 多朝向BIPV光伏发电量计算
- 分项建筑负荷建模与校准
- 供需匹配分析与可视化

**数据年份**：2023年（8760小时逐时数据）

**数据来源**：PVGIS气象数据
- 坐标：22.896°N, 113.480°E（广州南沙）
- 变量：直射辐照(Gb)、散射辐照(Gd)、反射辐照(Gr)、温度(T2m)

## 模块详解

### 1. pv_generation.py - 光伏发电计算模块

#### 1.1 建筑光伏配置

**球形主体**（总面积290 m²，分4个朝向）：
- 每个朝向：72.5 m²
- 不透明区域（HJT）：62.5 m²/朝向，效率21%
- 透明区域（CdTe）：10 m²/朝向，效率12%

**水平甲板**：
- 甲板区域（HJT）：67.6 m²，效率21%
- 玻璃栏杆（CdTe）：62.4 m²，效率12%

#### 1.2 核心函数

| 函数 | 功能 |
|------|------|
| `load_pvgis_csv()` | 解析PVGIS CSV，跳过元数据行，处理时间格式 |
| `total_irradiance_w_m2()` | 计算总辐照 = Gb + Gd + Gr |
| `temp_factor_c()` | 温度修正系数：1 - 0.004×(T-25) |
| `power_kw_one_surface()` | 单表面发电功率计算 |
| `build_hourly_pv()` | 汇总所有表面，应用微气候修正 |
| `plot_daily_monthly()` | 日/月尺度可视化 |
| `plot_daily_full_year()` | 全年日历热力图 |

#### 1.3 计算公式

**单表面发电功率**：
```
P = G × A × η × (1 - 0.004×(T-25)) / 1000
```
其中：
- G：总辐照度 (W/m²)
- A：面积 (m²)
- η：组件效率
- T：组件温度 (°C)，采用环境温度近似

**水面微气候修正**：
```
P_corrected = P × 1.05 × 1.012
```
- 反照率系数1.05：水面反射增加倾斜面辐照
- 冷却系数1.012：水体冷却降低组件温度

#### 1.4 数据验证

- 校验各朝向CSV时间戳一致性
- 校验pvgis_deck与pvgis_top是否相同（避免重复计算）
- 输出行数验证：8760行

#### 1.5 输出结果

- 年发电量：**110,888 kWh**
- 设计院参考值：55,580 kWh（口径不同，物理计算值作为基准）

### 2. load_generation.py - 建筑负荷建模模块

#### 2.1 三分项负荷模型

建筑总负荷分解为三个独立分项：

```
load_kW = base_kW + hvac_kW + aux_kW
```

| 分项 | 内容 | 年电量占比 | 特征 |
|------|------|-----------|------|
| base_kW | 照明、插座、机房、控制系统 | 30% | 全年存在，工作日/周末差异 |
| hvac_kW | 空调系统 | 60% | 仅4-10月，日内白天为主 |
| aux_kW | 水泵、室外照明、通风 | 10% | 傍晚夜间较重 |

#### 2.2 核心函数

| 函数 | 功能 |
|------|------|
| `_legal_holiday_dates_2023()` | 获取中国法定假日 |
| `_is_weekend_schedule()` | 判断是否使用周末形状（含调休处理） |
| `_raw_profiles()` | 生成未缩放的负荷形状序列 |
| `build_load()` | 分项缩放至目标电量 |
| `plot_daily_monthly()` | 日/月尺度可视化（月度为三分项堆叠） |
| `plot_typical_day_stack()` | 典型冬/夏日分项叠加图 |

#### 2.3 日内负荷形状

**基础负荷**（参考ASHRAE 90.1）：
- 工作日：日间高峰（0.7-1.0），夜间低谷（0.3）
- 周末：整体降低，日内波动平缓

**HVAC负荷**：
- 工作日：白天高峰（0.6-1.0），夜间为0
- 周末：整体降低
- 月度强度调制：4月0.30 → 7-8月1.00 → 10月0.40

**附属负荷**：
- 全年统一形状
- 傍晚夜间为主（18:00-23:00峰值）

#### 2.4 节假日处理

**数据来源**：
- `holidays`库：中国法定假日
- 国务院2023年放假调休表：补充调休日期

**处理规则**：
- 法定假日：使用周末形状
- 调休补班日：强制使用工作日形状

#### 2.5 校准验证

目标口径（与设计院资料一致）：
- 全年总电量：60,461 kWh
- HVAC占比：60%
- 基础占比：30%
- 附属占比：10%

**验证结果**：
```
年总负荷:     60,461.0 kWh   (目标 60,461.0 kWh)
  - 基础:    18,138.3 kWh (30.0 %, 目标 30 %)
  - HVAC:    36,276.6 kWh (60.0 %, 目标 60 %)
  - 附属:    6,046.1 kWh (10.0 %, 目标 10 %)
```

## 技术难点与解决方案

### 1. 多朝向辐照数据处理

**问题**：PVGIS输出6个CSV文件，需确保时间戳对齐，避免重复计算。

**解决方案**：
- MD5校验：验证pvgis_deck与pvgis_top是否相同
- 时间戳一致性检查：各文件datetime列必须完全一致
- 水平面辐照只计入一次

### 2. 负荷模型校准

**问题**：初始模型年电量达168 MWh，与设计院60 MWh口径相差近3倍。

**解决方案**：
- 采用分项建模：基础/HVAC/附属独立建模
- 按目标电量反推缩放系数
- 保留物理形状（日内曲线、季节性），仅调整量级

### 3. 节假日与调休处理

**问题**：中国调休制度复杂，补班日需强制使用工作日形状。

**解决方案**：
- 结合`holidays`库与国务院官方调休表
- 建立`MAKEUP_WORKDAYS_2023`集合，优先级高于周末判断

### 4. 水面微气候影响量化

**问题**：水上建筑的光伏效率与陆上不同，需量化差异。

**解决方案**：
- 文献调研确定修正系数
- 反照率系数1.05（水面反射增强）
- 冷却系数1.012（水体降温效应）

## 使用方法

### 环境配置

```bash
# 安装依赖
pip install -r requirements.txt
```

依赖清单：
- pandas >= 2.0
- numpy >= 1.24
- matplotlib >= 3.7
- holidays >= 0.45

### 运行流程

```bash
# 步骤1：光伏发电计算
python pv_generation.py
# 输出：output/pv_generation_8760.csv
#       plots/pv_*.png (4张图)

# 步骤2：负荷建模（依赖步骤1输出）
python load_generation.py
# 输出：output/load_8760.csv
#       plots/load_*.png (5张图)

# 步骤3：供需对比分析
python pv_load_daily_compare.py
# 输出：plots/pv_load_daily_compare.png
#       plots/pv_load_weekly_hourly_overlay.png
```

### 输出文件格式

**pv_generation_8760.csv**：
```
datetime, pv_kW
2023-01-01 00:00:00, 0.00
2023-01-01 01:00:00, 0.00
...
```

**load_8760.csv**：
```
datetime, base_kW, hvac_kW, aux_kW, load_kW
2023-01-01 00:00:00, 2.15, 0.00, 0.82, 2.97
...
```
